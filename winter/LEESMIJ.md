# Seafox Winter, tijdelijk op een tweede adres

Deze map bevat het nieuwe ontwerp in zijn wintereditie, zodat het naast het huidige ontwerp bekeken kan worden:

- Huidig ontwerp: `https://wimbroos1.github.io/Seafox/`
- Seafox Winter: `https://wimbroos1.github.io/Seafox/winter/`

De map is een kopie van de branch `modern-ontwerp-kerst` (voorstel 3). Het enige verschil is dat de agenda uit de gewone `data/availability.json` van de site wordt gelezen, zodat beide ontwerpen dezelfde beschikbaarheid tonen. Het oude adres `nieuw/` stuurt door naar deze map.

Na de keuze mogen deze mappen weg. Wordt het nieuwe ontwerp gekozen, voeg dan voorstel 3 samen: dat zet het op het hoofdadres.
