# Nieuw ontwerp, tijdelijk op een tweede adres

Deze map bevat het nieuwe ontwerp (donker zee-thema, echte foto's, winterthema, extra pagina's) zodat het naast het huidige ontwerp bekeken kan worden:

- Huidig ontwerp: `https://wimbroos1.github.io/Seafox/`
- Nieuw ontwerp: `https://wimbroos1.github.io/Seafox/nieuw/`

De map is een kopie van de branch `modern-ontwerp-kerst` (voorstel 3). Het enige verschil is dat de agenda uit de gewone `data/availability.json` van de site wordt gelezen, zodat beide ontwerpen dezelfde beschikbaarheid tonen.

Na de keuze mag deze map weg. Wordt het nieuwe ontwerp gekozen, voeg dan voorstel 3 samen: dat zet het nieuwe ontwerp op het hoofdadres.
